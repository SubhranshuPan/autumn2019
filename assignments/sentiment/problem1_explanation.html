🎯 Background: The Three Ingredients

We want a machine to read a review and decide: positive (+1) or negative (−1)? The machinery has three parts (from Lecture 2: Machine Learning I):

Key Concepts
ConceptWhat It IsExample
Feature vector $\phi(x)$ Bag-of-words: count how many times each word appears "pretty bad" → {pretty: 1, bad: 1}
Weight vector $\mathbf{w}$ A number per word: "how positive is this word?" {pretty: 0.3, bad: −0.8, …}
Score Dot product $\mathbf{w} \cdot \phi(x)$ $0.3 \times 1 + (-0.8) \times 1 = -0.5$

If the score is positive → predict +1. If negative → predict −1.

📝 Part 1a: SGD with Hinge Loss

The Dataset

#ReviewLabel $y$Feature vector $\phi(x)$
1pretty bad−1{pretty: 1, bad: 1}
2good plot+1{good: 1, plot: 1}
3not good−1{not: 1, good: 1}
4pretty scenery+1{pretty: 1, scenery: 1}

The Hinge Loss

Definition $$\text{Loss}_{\text{hinge}}(x, y, \mathbf{w}) = \max\!\big\{0, \;\; 1 - \underbrace{(\mathbf{w} \cdot \phi(x)) \cdot y}_{\text{margin}}\big\}$$
💡 What is the margin?

The margin = (score) × (true label) = $(\mathbf{w} \cdot \phi(x)) \cdot y$.

It measures "how confidently correct" the prediction is:

  • margin > 1 → Correct AND confident → Loss = 0 → No update ✅
  • margin < 1 → Wrong OR not confident enough → Loss > 0 → Need to update ⚠️
  • margin = 1 → Exactly on boundary → Problem says gradient = 0 (no update)

The Gradient & Update Rule

Gradient of Hinge Loss $$\nabla_{\mathbf{w}} \text{Loss}_{\text{hinge}} = \begin{cases} -\phi(x) \cdot y & \text{if margin} < 1 \\[6pt] \mathbf{0} & \text{if margin} \geq 1 \end{cases}$$

The SGD update rule says: subtract the gradient (scaled by step size $\eta$).

SGD Update $$\mathbf{w} \;\leftarrow\; \mathbf{w} \;-\; \eta \cdot \nabla_{\mathbf{w}} \text{Loss}_{\text{hinge}}$$

When margin < 1 (the case where we actually update), substituting the gradient in:

Update (when margin < 1) $$\mathbf{w} \;\leftarrow\; \mathbf{w} \;-\; \eta \cdot \big(-\phi(x) \cdot y\big)$$

The two negatives cancel, giving us:

$$\boxed{\;\mathbf{w} \;\leftarrow\; \mathbf{w} \;+\; \eta \cdot \phi(x) \cdot y\;}$$
💡 What does this mean in plain English?

When we need to update, for each word in the review:

  • If the review is positive ($y = +1$): increase that word's weight by $\eta$
  • If the review is negative ($y = -1$): decrease that word's weight by $\eta$

Words not in the review are untouched. With $\eta = 0.5$, each update nudges by $\pm 0.5$.

🔒 Part 1b: Proving Linear Inseparability

The Task

Create 4 mini-reviews using only "not", "good", "bad" with intuitive labels, then prove that no linear classifier can achieve zero error. Finally, propose a fix.

The Dataset

#ReviewLabel $y$Feature vector $\phi(x)$
1good+1{good: 1}
2bad−1{bad: 1}
3not good−1{not: 1, good: 1}
4not bad+1{not: 1, bad: 1}
💡 Why these labels make sense
  • "good" → obviously positive ✅
  • "bad" → obviously negative ❌
  • "not good" → negated positive → negative ❌
  • "not bad" → negated negative → positive ✅

The Proof

⚠️ Important

This proof is about any linear classifier — not about SGD or any specific algorithm. No matter how the weights are chosen (by hand, by training, by magic), it's impossible to get zero error.

Proof by Contradiction

A linear classifier predicts $\text{sign}(\mathbf{w} \cdot \phi(x))$. Let the weights be $w_{\text{good}}$, $w_{\text{bad}}$, $w_{\text{not}}$.

For zero error, we need all four score-times-label products to be positive (correct predictions). Writing out the four requirements:

ReviewRequiredInequalityLabel
"good" → +1 $\mathbf{w} \cdot \phi > 0$ $w_{\text{good}} > 0$ (i)
"bad" → −1 $\mathbf{w} \cdot \phi < 0$ $w_{\text{bad}} < 0$ (ii)
"not good" → −1 $\mathbf{w} \cdot \phi < 0$ $w_{\text{not}} + w_{\text{good}} < 0$ (iii)
"not bad" → +1 $\mathbf{w} \cdot \phi > 0$ $w_{\text{not}} + w_{\text{bad}} > 0$ (iv)

Now we derive the contradiction in three steps:

From (iii):   $w_{\text{not}} + w_{\text{good}} < 0$  ⟹  $w_{\text{not}} < -w_{\text{good}}$

From (iv):   $w_{\text{not}} + w_{\text{bad}} > 0$  ⟹  $w_{\text{not}} > -w_{\text{bad}}$

Combining:   $-w_{\text{bad}} < w_{\text{not}} < -w_{\text{good}}$

This requires  $-w_{\text{bad}} < -w_{\text{good}}$,  which means  $w_{\text{good}} < w_{\text{bad}}$.

But from (i) and (ii):  $w_{\text{good}} > 0$ and $w_{\text{bad}} < 0$, so $w_{\text{good}} > 0 > w_{\text{bad}}$, which means $w_{\text{good}} > w_{\text{bad}}$.

❌ CONTRADICTION!   $w_{\text{good}} < w_{\text{bad}}$  AND  $w_{\text{good}} > w_{\text{bad}}$  cannot both be true.

Therefore, no assignment of weights can satisfy all four constraints. ∎

Why Does This Happen?

The Core Issue

In a linear classifier, every word contributes independently to the score:

$\text{score} = w_{\text{not}} \times \phi_{\text{not}} + w_{\text{good}} \times \phi_{\text{good}} + w_{\text{bad}} \times \phi_{\text{bad}}$

The word "not" adds a fixed amount ($w_{\text{not}}$) no matter what word follows it. But we need:

  • "not" to push the score DOWN when paired with "good"
  • "not" to push the score UP when paired with "bad"

A single weight $w_{\text{not}}$ can't do both! This is essentially an XOR problem — and linear classifiers can't solve XOR.

The Fix: Add a Bigram Feature

✨ Proposed Feature

Add a "not good" bigram feature — a feature that fires only when the two consecutive words "not" and "good" appear together.

The updated feature vectors become:

ReviewUpdated $\phi(x)$
good{good: 1}
bad{bad: 1}
not good{not: 1, good: 1, not_good: 1}
not bad{not: 1, bad: 1}

Now let's verify it works. Set weights: $w_{\text{good}} = 1,\; w_{\text{bad}} = -1,\; w_{\text{not}} = 2,\; w_{\text{not\_good}} = -4$

ReviewScore computationScorePredictionCorrect?
good $1$ 1 +1 ✅
bad $-1$ −1 −1 ✅
not good $2 + 1 + (-4) = -1$ −1 −1 ✅
not bad $2 + (-1) = 1$ 1 +1 ✅
💡 Why does this work?

The bigram feature "not_good" gives the classifier a special knob that activates only when "not" and "good" appear together. Its large negative weight ($-4$) can overwhelm the individual effects of "not" (+2) and "good" (+1), correctly flipping the prediction to negative.

Meanwhile, "not bad" doesn't trigger the "not_good" feature, so it just gets the sum of "not" (+2) and "bad" (−1) = +1, correctly positive.

This is exactly the idea behind n-gram features — you'll implement this in Problem 3e (extractCharacterFeatures)!

🧠 Big Picture Takeaways

1

SGD processes examples one at a time and nudges weights in the right direction. Each update only looks at one example — it's fast but noisy. Over many examples, the noise averages out and you get good weights.

2

Hinge loss is smarter than 0-1 loss. It doesn't just penalize mistakes — it also penalizes being "right but not confident" (margin < 1). This extra push toward confident predictions is what makes SVMs so effective.

3

Linear classifiers have fundamental limits. They can only draw a single hyperplane to separate positive from negative. When the truth requires considering interactions between words (like "not" flipping "good"), bag-of-words features fail. This is why feature engineering (bigrams, n-grams) or non-linear models (neural networks) matter.

4

Feature engineering = giving the model the right "vocabulary." Unigrams (single words) can't capture negation. Bigrams ("not good") can. This exact idea appears again in Problem 3e, where character n-grams capture sub-word patterns that word features miss.

🎬 Problem 2: Predicting Movie Ratings

Now we shift gears. Instead of classifying reviews as positive/negative, we want to predict a numeric rating between 0 and 1. This introduces a non-linear predictor and the squared loss.

Setup
ComponentWhat It Is
Predictor $\sigma(\mathbf{w} \cdot \phi(x))$ — the logistic (sigmoid) function applied to the score
Logistic function $\sigma(z) = \dfrac{1}{1 + e^{-z}}$ — squashes any real number into the range $(0, 1)$
Rating $y$ A real number in $[0, 1]$ (e.g., 0.8 = pretty good, 0.2 = pretty bad)
Loss Squared loss — penalizes the squared difference between prediction and truth
💡 Why use the sigmoid?

The raw score $\mathbf{w} \cdot \phi(x)$ can be any real number (−∞ to +∞). But our rating $y$ is between 0 and 1. The sigmoid function squashes the score into that range — large positive scores become close to 1, large negative scores become close to 0, and zero maps to 0.5.

📐 Part 2a: The Loss Function

We want to measure how bad our prediction is. We're using squared loss, so we take the difference between our prediction and the true value, and square it.

Building it step by step

Step 1: Our prediction for input $x$ is:

$\hat{y} = \sigma(\mathbf{w} \cdot \phi(x))$

Step 2: The error is how far off we are:

$\text{error} = \hat{y} - y = \sigma(\mathbf{w} \cdot \phi(x)) - y$

Step 3: Square the error to make it always positive and penalize large errors more:

✅ Answer — Part 2a

$$\text{Loss}(x, y, \mathbf{w}) = \big(\sigma(\mathbf{w} \cdot \phi(x)) - y\big)^2$$
💡 Intuition

If our prediction $\sigma(\mathbf{w} \cdot \phi(x)) = 0.9$ and the true rating is $y = 0.8$, the loss is $(0.9 - 0.8)^2 = 0.01$ — small error! If we predicted 0.2 instead, the loss would be $(0.2 - 0.8)^2 = 0.36$ — big error. The squaring amplifies large mistakes.

📊 Part 2b: Computing the Gradient

To use gradient descent, we need to know: "in which direction should I change $\mathbf{w}$ to reduce the loss?" That's what the gradient tells us.

Let's define a shorthand to keep things clean:

Shorthand $$p \;=\; \sigma(\mathbf{w} \cdot \phi(x))$$

$p$ is our predicted value — a number between 0 and 1.

Now we apply the chain rule step by step. Think of the loss as a chain of nested functions:

The Chain of Functions

$\text{Loss} = \big(\underbrace{\sigma(\underbrace{\mathbf{w} \cdot \phi(x)}_{\text{inner}})}_{{p}} - y\big)^2$

To differentiate, we peel off layers from outside in:

LayerFunctionDerivative
Outer $(\cdot)^2$ $2(p - y)$
Middle $\sigma(\cdot)$ $p(1 - p)$   ← this is a known property of the sigmoid!
Inner $\mathbf{w} \cdot \phi(x)$ $\phi(x)$
💡 Key fact about the sigmoid

The derivative of the sigmoid function has a beautiful property:

$\sigma'(z) = \sigma(z) \cdot (1 - \sigma(z)) = p \cdot (1 - p)$

This means the sigmoid's slope is largest at $z = 0$ (where $p = 0.5$) and approaches zero as $z$ gets very large or very small. This fact will be crucial in parts 2c and 2d.

Multiply all three layers together by the chain rule:

✅ Answer — Part 2b

$$\nabla_{\mathbf{w}} \text{Loss}(x, y, \mathbf{w}) = 2(p - y) \cdot p(1 - p) \cdot \phi(x)$$

where $p = \sigma(\mathbf{w} \cdot \phi(x))$

💡 Reading the gradient

The gradient has three factors — each tells you something:

  • $2(p - y)$ — how wrong is the prediction? (direction + magnitude of error)
  • $p(1-p)$ — how sensitive is the sigmoid right now? (large near $p=0.5$, small near 0 or 1)
  • $\phi(x)$ — which features are active? (update only those features)

🌫️ Part 2c: Vanishing Gradients

Now we focus on a specific case: one datapoint with $y = 1$ and some arbitrary $\phi(x)$. Can we make the gradient vanishingly small?

Plugging in $y = 1$

From Part 2b, the gradient is $2(p - y) \cdot p(1-p) \cdot \phi(x)$. With $y = 1$:

Gradient when $y = 1$ $$\nabla_{\mathbf{w}} \text{Loss} = 2(p - 1) \cdot p(1-p) \cdot \phi(x)$$

Since $(p - 1) = -(1 - p)$, this simplifies to:

$$= -2p(1 - p)^2 \cdot \phi(x)$$

The magnitude (length) of the gradient is:

Magnitude $$\|\nabla_{\mathbf{w}} \text{Loss}\| = 2p(1-p)^2 \cdot \|\phi(x)\|$$

Since $\|\phi(x)\|$ is fixed (it depends on the input, not on $\mathbf{w}$), we only need to look at the scalar factor $f(p) = p(1-p)^2$.

Can we make this arbitrarily small?

The key observation

Remember: $p = \sigma(\mathbf{w} \cdot \phi(x))$.

  • As $\mathbf{w} \cdot \phi(x) \to +\infty$ (make $\mathbf{w}$ very large in the direction of $\phi(x)$):
    → $p \to 1$
    → $(1-p) \to 0$
    → $p(1-p)^2 \to 1 \cdot 0^2 = 0$ ✅

So yes! By making $\|\mathbf{w}\|$ large enough (pointing in the direction of $\phi(x)$), we push $p$ arbitrarily close to 1, which makes $(1-p)^2$ arbitrarily close to 0.

Can it be exactly zero?

⚠️ No — never exactly zero!

For any finite $\mathbf{w}$, the sigmoid always satisfies $0 < p < 1$ (it never actually reaches 0 or 1). Therefore:

  • $p > 0$ → the $p$ factor is always positive
  • $(1-p) > 0$ → the $(1-p)^2$ factor is always positive

So $p(1-p)^2 > 0$ always. The gradient can get arbitrarily close to zero, but never exactly zero (assuming $\phi(x) \neq \mathbf{0}$).

✅ Answer — Part 2c

Yes, the gradient magnitude can be made arbitrarily small by making $\mathbf{w}$ large in the direction of $\phi(x)$, which pushes $p \to 1$.

No, it can never be exactly zero for finite $\mathbf{w}$, because the sigmoid is always strictly between 0 and 1.

💡 This is the Vanishing Gradient Problem!

This is exactly what happens in deep neural networks. When the sigmoid is saturated (output near 0 or 1), its derivative $p(1-p)$ is nearly zero. This means gradient descent takes tiny steps and learning slows to a crawl — even when $\mathbf{w}$ is far from optimal.

This is one reason why modern networks use ReLU instead of sigmoid — ReLU doesn't saturate for positive inputs.

📈 Part 2d: Maximum Gradient Magnitude

Same setup: $y = 1$, arbitrary $\phi(x)$. What's the largest the gradient can get?

From Part 2c, the gradient magnitude is $2 \cdot f(p) \cdot \|\phi(x)\|$ where $f(p) = p(1-p)^2$. We need to maximize $f(p)$ for $p \in (0, 1)$.

Finding the maximum of $f(p) = p(1-p)^2$

Calculus — take the derivative and set it to zero

Step 1: Expand using the product rule:

$f'(p) = (1-p)^2 + p \cdot 2(1-p)(-1)$

Step 2: Factor out $(1-p)$:

$f'(p) = (1-p)\big[(1-p) - 2p\big] = (1-p)(1 - 3p)$

Step 3: Set $f'(p) = 0$:

  • $(1-p) = 0$ → $p = 1$ (boundary, where $f = 0$)
  • $(1-3p) = 0$ → $p = \tfrac{1}{3}$ ← this is our candidate!
Evaluating $f$ at the critical point

$f\!\left(\tfrac{1}{3}\right) = \tfrac{1}{3} \cdot \left(\tfrac{2}{3}\right)^{\!2} = \tfrac{1}{3} \cdot \tfrac{4}{9} = \dfrac{4}{27}$

Why is this the maximum? $f(p)$ is continuous on $[0, 1]$ with $f(0) = 0$ and $f(1) = 0$. The only critical point in $(0, 1)$ is $p = \tfrac{1}{3}$, where $f > 0$. So it must be the maximum.

Therefore the maximum gradient magnitude is:

✅ Answer — Part 2d

$$\max \|\nabla_{\mathbf{w}} \text{Loss}\| = 2 \cdot \frac{4}{27} \cdot \|\phi(x)\| = \boxed{\dfrac{8}{27} \|\phi(x)\|}$$

Achieved when $p = \tfrac{1}{3}$, i.e., when $\sigma(\mathbf{w} \cdot \phi(x)) = \tfrac{1}{3}$.

💡 Intuition

The maximum gradient happens at $p = 1/3$, not at $p = 1/2$ (where the sigmoid slope is steepest). Why? Because there are two competing forces:

  • $p(1-p)$: the sigmoid slope, maximized at $p = 0.5$
  • $(p - 1)$: the error term (we want $p = 1$), whose magnitude is maximized when $p$ is small

The balance point $p = 1/3$ reflects the trade-off: the error is still large enough, and the sigmoid is still responsive enough, to produce the biggest gradient.

🔄 Part 2e: Transforming to Linear Regression

The loss with the sigmoid is non-convex — gradient descent might get stuck in local minima. Can we reformulate the problem so we can use plain old linear regression instead?

The Setup

Given
  • Dataset $\mathbf{D}$ with pairs $(x, y)$
  • There exists some $\mathbf{w}$ that achieves zero loss on $\mathbf{D}$ using the non-linear predictor $\sigma(\mathbf{w} \cdot \phi(x))$
  • Goal: transform $y \to y'$ so that linear regression on $(x, y')$ also yields zero loss

Deriving $y'$

Step-by-step reasoning

Step 1: Zero loss on original dataset $\mathbf{D}$ means:

$\sigma(\mathbf{w} \cdot \phi(x)) = y \quad \text{for all } (x,y)$

Step 2: Apply the inverse of sigmoid ($\sigma^{-1}$, called the logit function) to both sides:

$\mathbf{w} \cdot \phi(x) = \sigma^{-1}(y) = \ln\!\left(\dfrac{y}{1 - y}\right)$

Step 3: For linear regression on $\mathbf{D}'$ with zero loss, we need:

$\mathbf{w} \cdot \phi(x) = y'$

Step 4: Comparing Steps 2 and 3, we get:

$y' = \sigma^{-1}(y) = \ln\!\left(\dfrac{y}{1 - y}\right)$

✅ Answer — Part 2e

$$y' = \ln\!\left(\frac{y}{1-y}\right)$$

This is the logit function — the inverse of the sigmoid.

💡 Why does this work?

The sigmoid was "wrapping" the linear score into $[0, 1]$. By applying the inverse sigmoid (logit) to the labels $y$, we "unwrap" them back into the full real line. Now the target $y'$ lives in $(-\infty, +\infty)$, just like the linear predictor $\mathbf{w} \cdot \phi(x)$.

In other words: instead of fitting a complex non-linear model, we transform the data so that a simple linear model suffices. This is a powerful general technique!

⚠️ Requirement for this to work

The logit function $\ln(y/(1-y))$ is only defined when $0 < y < 1$. If $y = 0$ or $y = 1$, the logit is undefined ($-\infty$ or $+\infty$). This is fine for the problem since it states zero loss exists with the sigmoid predictor, which always outputs strictly between 0 and 1.

Justification / Proof

Original dataset $\mathbf{D}$: Uses predictor $\sigma(\mathbf{w} \cdot \phi(x))$ with squared loss.

$\text{Loss}_{\mathbf{D}} = (\sigma(\mathbf{w} \cdot \phi(x)) - y)^2 = 0$

This means $\sigma(\mathbf{w} \cdot \phi(x)) = y$, which means $\mathbf{w} \cdot \phi(x) = \ln(y/(1-y))$.

Transformed dataset $\mathbf{D}'$: Uses linear predictor $\mathbf{w} \cdot \phi(x)$ with squared loss.

$\text{Loss}_{\mathbf{D}'} = (\mathbf{w} \cdot \phi(x) - y')^2$

Setting $y' = \ln(y/(1-y))$ gives:

$\text{Loss}_{\mathbf{D}'} = (\mathbf{w} \cdot \phi(x) - \ln(y/(1-y)))^2 = 0$ ✅

The same $\mathbf{w}$ achieves zero loss on both datasets. Since least squares on $\mathbf{D}'$ is a convex problem (quadratic in $\mathbf{w}$), gradient descent is guaranteed to converge to this global minimum $\mathbf{w}^*$.

🧠 Problem 2 — Big Picture Takeaways

1

The sigmoid squashes scores into $[0,1]$. This is useful for predicting probabilities or ratings, but introduces non-linearity that makes the loss non-convex.

2

Chain rule is your best friend. Complex loss functions are just nested functions. Peel off layers from outside in: outer derivative × middle derivative × inner derivative.

3

Vanishing gradients are real and dangerous. When the sigmoid saturates ($p$ near 0 or 1), its derivative $p(1-p) \approx 0$, and gradient descent practically stalls. This is why deep learning moved to ReLU activations.

4

You can "undo" non-linearity by transforming the data. The logit transform $y' = \ln(y/(1-y))$ converts a non-convex problem into a convex (linear regression) problem. This is the core idea behind generalized linear models in statistics.
